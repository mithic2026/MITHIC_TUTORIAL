# MITHIC Workshop Notebook

This repository contains materials for the **MITHIC workshop**; a hands-on exploration of information-theoretic and data analysis methods using Jupyter notebooks.

---

## Getting Started

### 1. Clone or Download the Repository

**Option A: Clone via Git:**
```bash
git clone <your-repo-url>
cd mithic-workshop
```

**Option B: Download ZIP:**  
Click the green **Code** button on GitHub → **Download ZIP**, then extract the folder locally.

> You can also **fork** this repository and work directly from your own GitHub account.

---

### 2. Set Up the Environment

This project uses **Conda** to manage dependencies. Run the following in your terminal:

```bash
# Create the environment
conda env create -f environment.yml

# Activate the environment
conda activate mithic-workshop
```

> **Prerequisites:** Make sure you have [Conda](https://docs.conda.io/en/latest/miniconda.html) installed before running these commands.

---

### 3. Launch the Notebook

Once the environment is active, start Jupyter Notebook:

```bash
jupyter notebook
```

Then open the workshop `.ipynb` file in your browser. Alternatively, open the file directly in **Visual Studio Code** with the Jupyter extension.

---

## Explore and Experiment

This workshop is designed to be **interactive and open-ended**. You are encouraged to:

- Modify the notebook and experiment with the code
- Upload and analyze your own datasets
- Use built-in datasets from [scikit-learn](https://scikit-learn.org/stable/api/sklearn.datasets.html)
